# VoiceSlide Movie — E2E QA チェックリスト

## 前提条件

| 項目 | 要件 |
|------|------|
| Node.js | v20 以上（確認環境: v22.22.0） |
| Python | 3.11 以上 |
| バックエンド | `backend/` が起動済み (`uvicorn main:app`) |
| 環境変数 | `.env.local` に Supabase / OpenRouter / Gemini キーが設定済み |
| ブラウザ | Chrome 最新安定版（推奨）または Safari / Firefox 最新版 |
| ネットワーク | 外部 API（OpenRouter, Gemini, Supabase Storage）へ到達可能 |

## テスト用アカウント・固定音声サンプルの準備

1. **テスト用 Supabase アカウント**
   - QA 専用のメールアドレスでログインできる状態にしておく
   - 既存プロジェクトが残っている場合はダッシュボードから削除し、クリーンな状態で開始する

2. **固定音声サンプル**
   - 短尺（30 秒以内）: 基本フローの高速検証用
   - 中尺（1〜3 分）: 標準ユースケース確認用
   - 長尺（5 分以上）: タイムアウト・パフォーマンス確認用
   - 形式: `.mp3` または `.wav`（サポート形式であること）
   - サンプルは `docs/qa/fixtures/` に配置し、バージョン管理に含める（サイズが大きい場合は `.gitignore` で除外し、取得手順を記載）

## 実行コマンド

```bash
# 1. ユニットテスト（全件、ウォッチなし）
npm test -- --watch=false

# 2. ビルド確認（TypeScript エラー・バンドルエラーの検出）
npm run build

# 3. ローカル起動（ポート 3010）
PORT=3010 npm run dev
```

## E2E テストステップ

### Step 1: 音声アップロード

| # | 操作 | Pass 基準 |
|---|------|-----------|
| 1.1 | ログイン後、メインページを開く | ワークフロー画面が表示される |
| 1.2 | 短尺音声ファイル (.mp3) をアップロード | アップロード進捗が表示され、完了後に波形 or 再生 UI が表示される |
| 1.3 | 対応外の形式（例: .txt）をアップロード | エラーメッセージが表示され、処理が進まない |
| 1.4 | 空ファイル（0 byte）をアップロード | エラーメッセージが表示される |
| 1.5 | アップロード中にページリロード | リロード後、状態が復元されるか確認（復元されない場合は再アップロードが可能であること） |

### Step 2: 文字起こし (Transcription)

| # | 操作 | Pass 基準 |
|---|------|-----------|
| 2.1 | アップロード完了後「文字起こし」を実行 | ポーリング UI が表示され、完了後にトランスクリプトテキストが画面に表示される |
| 2.2 | トランスクリプト完了後、テキスト内容を目視確認 | 音声内容と概ね一致している（固定サンプルなら期待テキストと比較） |
| 2.3 | `GET /api/transcribe-status/{job_id}` を確認 | ステータスが `completed` になっている |

### Step 3: Transcript Polish

| # | 操作 | Pass 基準 |
|---|------|-----------|
| 3.1 | トランスクリプト画面で「ポリッシュ」を実行 | テキストが整形・修正され、UI に反映される |
| 3.2 | ポリッシュ前後のテキストを比較 | 句読点・誤字の修正など、品質向上が確認できる |
| 3.3 | ポリッシュを複数回実行 | エラーにならず、結果が更新される |

### Step 4: Outline Generation

| # | 操作 | Pass 基準 |
|---|------|-----------|
| 4.1 | 「アウトライン生成」を実行 | アウトラインが生成され、セクション分割が表示される |
| 4.2 | 生成されたアウトラインの構造を確認 | スライド単位でタイトル・内容が分割されている |
| 4.3 | `GET /api/outline-status/{job_id}` を確認 | ステータスが `completed` |
| 4.4 | アウトラインを手動編集して保存 | 編集内容が保持される |

### Step 5: Slide Generation / Import

| # | 操作 | Pass 基準 |
|---|------|-----------|
| 5.1 | 「スライド生成」を実行 | バッチ処理が開始され、進捗が表示される |
| 5.2 | 全スライドの生成完了を待つ | すべてのスライドがサムネイル付きで表示される |
| 5.3 | `GET /api/batch-status/{job_id}` を確認 | 全スライドが `completed` |
| 5.4 | 個別スライドのテキスト編集 | 編集が即座に反映される |
| 5.5 | スライドの追加・複製・削除 | 操作後にスライド一覧が正しく更新される |
| 5.6 | 外部スライド画像のインポート（`POST /api/upload-slides/{job_id}`） | アップロードしたスライドが一覧に反映される |

### Step 6: AI Mapping

| # | 操作 | Pass 基準 |
|---|------|-----------|
| 6.1 | 「AI マッピング」を実行 | 音声セグメントとスライドの対応付けが完了する |
| 6.2 | マッピング結果を確認 | 各スライドに開始・終了タイムスタンプが割り当てられている |
| 6.3 | マッピングを手動で微調整（可能な場合） | 調整後の値が保持される |

### Step 7: Video Generation

| # | 操作 | Pass 基準 |
|---|------|-----------|
| 7.1 | 「動画生成」を実行 | 動画のレンダリングが開始され、進捗が表示される |
| 7.2 | 生成完了を待つ | プレビュー動画がブラウザ上で再生可能になる |
| 7.3 | 動画を再生して確認 | 音声・スライド切替・タイミングが正しく同期している |
| 7.4 | `GET /api/video/{job_id}` でストリーミング再生 | 動画が途切れずに再生される |

### Step 8: Download

| # | 操作 | Pass 基準 |
|---|------|-----------|
| 8.1 | 「ダウンロード」ボタンをクリック | ファイルダウンロードが開始される |
| 8.2 | ダウンロードしたファイルをローカルで再生 | ブラウザプレビューと同一の内容が再生される |
| 8.3 | ファイルサイズが 0 でないことを確認 | 有効な動画ファイルである |

### Step 9: Dashboard Restore

| # | 操作 | Pass 基準 |
|---|------|-----------|
| 9.1 | ダッシュボード (`/dashboard`) を開く | 作成したプロジェクトが一覧に表示される |
| 9.2 | ステータス表示を確認 | 現在のステップ（例:「動画生成完了」）が正しく表示されている |
| 9.3 | プロジェクトをクリックして復元 | ワークフローが該当ステップの状態で復元される |
| 9.4 | 復元後、動画を再生 | 以前生成した動画が再生できる |
| 9.5 | 復元後、途中のステップからやり直し | 再生成が正常に動作する |
| 9.6 | プロジェクトを削除 | ダッシュボードから消え、Supabase Storage のデータも削除される |

## 失敗時のログ取得

テストステップが失敗した場合、以下のログを取得して報告に添付する。

### ブラウザ側

1. Chrome DevTools → **Console** タブのエラーログをコピー
2. **Network** タブで失敗したリクエストの URL・ステータスコード・レスポンスボディを記録
3. 必要に応じてスクリーンショットを取得

### バックエンド側

```bash
# バックエンドのログ出力を確認
# uvicorn のターミナル出力、または以下で直近のログを確認
tail -100 backend/logs/*.log  # ログファイルがある場合
```

### フロントエンド側

```bash
# Next.js サーバーのターミナル出力を確認
# PORT=3010 npm run dev の出力にエラーが表示されていないか
```

### 報告テンプレート

```
## 不具合報告
- ステップ番号: (例: 5.2)
- 操作内容:
- 期待結果:
- 実際の結果:
- ブラウザコンソールログ: (貼付)
- ネットワークエラー: (URL, ステータスコード, レスポンス)
- バックエンドログ: (貼付)
- スクリーンショット: (添付)
- 再現率: (毎回 / 時々 / 初回のみ)
```
