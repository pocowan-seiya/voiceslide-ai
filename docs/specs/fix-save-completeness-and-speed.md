# 仕様書: プロジェクト保存完全性修正 & 速度改善

## 概要
プロジェクト保存/復元で欠落しているフィールドの修正と、スライド生成速度の改善。

## Sprint 1: 保存フィールドの完全性修正

### 問題点
以下のユーザー編集可能な状態が `buildSettings()` および restore ロジックに含まれていない:
1. `playbackRate` — 音声再生速度
2. `bgmMixed` — BGMミックス済みフラグ  
3. `facecamUploaded` — フェイスカムアップロード済みフラグ

### 修正内容
- `buildSettings()` (app/page.tsx:532) に3フィールドを追加
- restore ロジック (app/page.tsx:506-523) に3フィールドの復元を追加
- `ProjectSettings` 型定義 (lib/supabase/types.ts) を実態に合わせて更新

## Sprint 2: スライドプレビューURL検証の改善

### 問題点
restore 時に最初の1枚のURLしか有効性チェックしていない (app/page.tsx:431-433)。
後半のスライドが壊れていても検出されない。

### 修正内容
- 全スライドプレビューURLを並列でHEADリクエストして検証
- 壊れたURLのみ除外し、有効なスライドは保持
- パフォーマンスのため Promise.allSettled を使用

## Sprint 3: Playwright ブラウザ再利用（速度改善）

### 問題点
ai_slide_generator.py でバッチ毎に新規ブラウザインスタンスを起動している。
起動に3-5秒かかる。

### 修正内容
- グローバルブラウザプールを導入
- 既存ブラウザがあればそれを再利用
- アイドルタイムアウト後に自動クリーンアップ

## 品質基準
- 全既存テスト(70件)がパスすること
- npm run build が成功すること
- 既存の保存/復元フローに回帰がないこと
