# VoiSlide Movie 公式サポートFAQ

編集するとAIの回答に反映されます。

## エラー: 429 quota exceeded (OpenAI)

**症状**: 
```
Error code: 429 - {'error': {'message': 'You exceeded your current quota...'}}
```

**原因**: OpenAI APIの利用制限（クォータ）に達しています。

**対応方法**:
1. https://platform.openai.com/account/usage でクォータを確認
2. 残高が0の場合は「Billing」から追加チャージ
3. または別のOpenAI APIキーを使用してください
4. 月初にクォータがリセットされます

---

## エラー: 401 invalid_api_key (OpenAI)

**症状**: 
```
Error code: 401 - {'error': {'message': 'Incorrect API key provided: xxxx...'}}
```

**原因**: 入力されたOpenAI APIキーの形式が正しくありません。正しいAPIキーは `sk-` で始まる長い文字列です。

**対応方法**:
1. https://platform.openai.com/api-keys にアクセス
2. 「Create new secret key」ボタンをクリック
3. 生成されたキー（`sk-proj-...` で始まる文字列）をコピー
4. VoiSlide Movieの「API設定」→「OpenAI API Key」に貼り付け

**よくある間違い**:
- サービス名（voislide など）を入力している
- Gemini APIキーをOpenAI欄に入力している
- キーの一部だけをコピーしている

## エラー: Gemini API key not valid

**症状**: 
```
Gemini APIキーが無効です
```

**原因**: 入力されたGemini APIキーが正しくないか、無効になっています。

**対応方法**:
1. https://aistudio.google.com/app/apikey にアクセス
2. 新しいAPIキーを生成
3. 画面上部の「API設定」から正しいキーを入力

---

## エラー: 429 Resource exhausted / Quota exceeded (Gemini)

**症状**: 
```
429 Resource exhausted / Quota exceeded
```
または「Gemini APIが非常に混み合っています」というエラーメッセージ

**AIチャットでの表示例**:
```
エラー内容: [2026/01/29 18:00:19] Failed to fetch
ステップ: audio_upload または transcript_polish
モード: full-ai
```
※ 「Failed to fetch」と表示される場合も、多くはこのエラーが原因です。

**原因**: **Gemini APIの無料枠（Free Tier）を使用している**ため、1分あたり15リクエスト、または1日のリクエスト上限に達しています。

**【重要】お支払い設定が必要です！**

VoiSlide Movieでスライドを快適に生成するには、Gemini APIの**従量課金プラン（Pay-as-you-go）**への切り替えが必要です。無料枠のままだと、長い動画のスライド生成中にこのエラーが発生しやすくなります。

**対応方法**:

☆ 以下の動画の**8分頃（8:00〜）**から、Gemini APIのお支払い設定の方法を解説しています：

🎬 **Gemini API 設定 解説動画（8:00〜）**
https://vimeo.com/1155922169/84cd283587?share=copy&fl=sv&fe=ci#t=478

この動画を見ながら設定を進めていただければ、スムーズに解決できます。

**手順の概要**:
1. Google AI Studio（https://aistudio.google.com/）にアクセス
2. 左メニューの「Settings」→「Billing」を開く
3. Google Cloud Platformとの連携を設定
4. お支払い方法（クレジットカード等）を登録
5. 従量課金が有効になると、制限が大幅に緩和されます

**従量課金のメリット**:
- 1分あたり1,500リクエスト以上（無料枠の100倍）
- 長い動画でも安定してスライド生成が可能
- 実際の利用量に応じた課金（使わなければ0円）

## エラー: CORS policy エラー

**症状**: 
```
Access to fetch has been blocked by CORS policy
```

**原因**: バックエンドサーバーとフロントエンドのURL設定の問題です。

**対応方法**:
1. ページをリロード（Ctrl+Shift+R または Cmd+Shift+R）
2. 解消しない場合は開発チームにお問い合わせください

---

## 動画生成が途中で止まる

**症状**: スライド生成や動画作成が途中で停止する

**原因**: 
- サーバーの一時的な負荷
- ブラウザのタブが非アクティブになった

**対応方法**:
1. ページをリロードして再試行
2. ブラウザのタブをアクティブに保つ
3. 長時間の処理中はPCをスリープさせない

---

## 字幕が音声とずれる

**症状**: 生成された動画で字幕のタイミングがずれている

**原因**: 音声ファイルの冒頭に無音部分がある可能性

**対応方法**:
1. 音声ファイルの冒頭の無音をカットして再アップロード
2. または「やり直す」ボタンで再生成

---

## イラストが生成されない

**症状**: イラストモードを選択したのにイラストが表示されない

**原因**: 
- イラスト生成に時間がかかっている
- Gemini APIのレート制限

**対応方法**:
1. しばらく待つ（イラスト生成は1枚5-10秒かかります）
2. 「イラスト再生成」ボタンでリトライ

---

## スライドのテキストが読みにくい

**症状**: 生成されたスライドの文字が小さすぎる、または背景と被っている

**対応方法**:
1. スライド編集エリアで該当スライドを選択
2. 「レイアウトのみ」ボタンでレイアウトを調整
3. または「全体」ボタンでフィードバックを入力して再生成

---

## OP/ED動画の結合ができない

**症状**: オープニング/エンディング動画を追加しても結合されない

**対応方法**:
1. 動画ファイルがMP4形式か確認
2. ファイルサイズが大きすぎる場合は圧縮して再アップロード
3. 「結合する」ボタンを押した後、処理完了まで待つ
